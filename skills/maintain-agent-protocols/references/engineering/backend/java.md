# Java 后端总览

适用 Java 后端服务。具体规则按子目录文件加载。

## 细分入口

- `java/architecture.md`：入口、分层和业务边界。
- `java/errors-and-resources.md`：错误、日志、资源释放和生命周期。
- `java/concurrency.md`：并发、异步、线程或运行时边界。
- `java/security-and-validation.md`：输入校验、安全整数、依赖和敏感信息。
- `java/verification.md`：测试、lint、race 或等价验证入口。

## 输出要求

- 说明本次任务涉及哪些 Java 子域。
- 说明安全、性能和验证是否覆盖。
