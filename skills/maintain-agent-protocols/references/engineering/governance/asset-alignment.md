# 能力资产一致性

## 核心规则

- prompt、helper、template、manual 等能力资产变更时必须同步检查一致性。
- 自动化审查只提供建议，不能替代维护者最终责任。
- 在线 PR 本地审查应避免修改维护者工作区。
- 能力资产包至少应对齐：适用范围、非目标、输入来源、输出格式、覆盖盲区表达、校验入口和故障回退方式。
- 若新增或调整技能能力，必须同步 `SKILL.md`、`agents/openai.yaml`、相关 reference、模板和验证脚本说明，避免只改其中一个入口。

## 输出要求

- 说明涉及哪些能力资产和校验入口。
- 说明是否已同步同一 bundle 的技能入口、reference、template、agent metadata 和验证入口。
