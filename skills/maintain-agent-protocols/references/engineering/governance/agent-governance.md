# Agent 治理总览

适用 Agent 协作能力、规则路由能力、协议维护质量和提示语/模板一致性。

## 细分入口

- `capability-boundary.md`：能力边界、非目标、检查点和失败路径。
- `evidence-and-scope.md`：证据、不确定性、审查范围和全量审查边界。
- `asset-alignment.md`：prompt、helper、template、manual 等能力资产一致性。
- `review-antipatterns.md`：掩盖根因反模式和渐进式加载。

## 输出要求

- 说明检查范围、未检查范围、证据、结论适用范围和剩余风险。
- 对发现的问题分类为已解决、延后处理、明确排除或后续任务。
