# Data Access

适用 Repository、事务、分页过滤、缓存一致性和存储访问。

核心规则：

- Repository 只负责数据访问和查询组装，不承载业务校验。
- 多记录写入、删除和状态迁移必须保证事务一致性。
- 分页列表的分页、过滤和排序必须在存储层或后端查询层完成，禁止全量拉取后手工分页。
- 小集合或枚举列表可一次读取，但必须有明确数据上限，避免把可增长业务数据伪装成小集合。
- 如涉及缓存、读模型或派生索引，写入成功后必须处理一致性，避免读到旧状态。
- 查询组装必须使用参数化或安全映射，避免不受信输入进入查询解释器。
- 数据访问错误要保留诊断上下文，但用户可见消息不得泄露内部实现。

验证与输出：

- 说明 Repository 边界、事务、分页过滤和缓存处理。
- 说明查询安全和错误表达。
