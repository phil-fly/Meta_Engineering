# Auth And Permission

适用登录、认证、授权、资源归属、权限渲染和默认拒绝边界。

核心规则：

- 身份认证和权限授权必须分离，认证成功不等于有权访问资源。
- 受保护接口必须失败关闭；缺少权限元数据时默认拒绝。
- 服务间调用必须携带调用方上下文，避免服务边界丢失身份。
- 资源级访问必须在服务端校验资源归属、租户边界或授权范围。
- CRUD、批量、导出和管理操作必须保持一致权限边界。
- 登录、验证码、找回密码等公开入口必须有防滥用控制。
- 前端隐藏控件不能替代后端权限 enforcement。
- 前端登录态必须来自统一入口，401/403 必须进入统一反馈路径。

验证与输出：

- 说明认证、授权、资源归属和防滥用是否覆盖。
- 说明前端展示控制和后端最终边界是否分离。
