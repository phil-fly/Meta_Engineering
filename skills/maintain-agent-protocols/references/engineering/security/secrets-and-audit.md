# 密钥保护与审计

密钥、令牌、证书、私钥、连接串和凭证不得提交到仓库，也不得出现在日志、错误响应或审计明文中。

## 核心规则

- 日志、错误响应、审计事件和调试输出必须脱敏或省略敏感字段。
- 涉及权限、策略、密钥、网关、租户或生产数据的管理操作必须可审计。
- 审计事件应包含 actor、target、操作意图、结果、时间和 request id。
- 审计不得泄露原始密钥、令牌、密码、证书、敏感请求体或隐私数据。
- 结构化日志应至少稳定表达 `service`、`event`、`level`、`request_id` 和 `outcome`；可选字段也应保持稳定键名。

## 输出要求

- 说明敏感字段处理方式。
- 说明审计事件落点、字段和可追踪性。
