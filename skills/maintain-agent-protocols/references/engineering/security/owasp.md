# OWASP Top 10 检查项

安全审查、敏感功能开发和高风险变更应按需读取本文件。

## 检查项

- A01 访问控制失效：服务端权限、资源归属、租户边界、IDOR 和最小权限。
- A02 加密机制失效：强加密、密码安全哈希、密钥管理、安全随机数和传输保护。
- A03 注入攻击：SQL、NoSQL、命令、表达式、LDAP、XPath 等注入防护。
- A04 不安全设计：威胁建模、速率限制、业务约束、信任边界和纵深防御。
- A05 安全配置错误：默认凭证、调试端点、详细错误、安全头和基线配置。
- A06 易受攻击和过时组件：依赖扫描、升级策略、漏洞响应和例外说明。
- A07 身份认证失效：密码策略、MFA、会话管理、暴力破解防护和凭证保护。
- A08 软件和数据完整性失效：安全反序列化、签名校验、交付链保护和更新完整性。
- A09 安全日志和监控失效：认证、授权、数据访问、异常行为审计和告警。
- A10 服务端请求伪造：URL 白名单、内网地址阻断、协议限制、重定向、超时和大小限制。

## 审查要求

- 审查时必须先声明本次覆盖哪些 OWASP 项、未覆盖哪些项以及原因。
- 对可判断的项，应说明证据、影响和对应控制点，而不是只给通过/不通过结论。
- 涉及访问控制、注入、认证、配置、完整性、日志监控和 SSRF 的场景，应优先回链到当前技能对应 working layer 文件进行实现或修复。

## 输出要求

- 只对本次范围内可判断的项给结论。
- 无证据覆盖的项必须标注未检查或无法确认。
