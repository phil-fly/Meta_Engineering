# 前端可访问性

适用按钮、链接、表单、Dialog、Drawer、Menu、Popover、Tooltip、Tabs、Combobox、表格、空态、错误态、紧凑布局和键盘交互。

## 核心约束

- CON-FE-A11Y-001 语义入口：可交互元素必须使用正确语义或等价 ARIA；按钮、链接、输入、菜单、tab、dialog 和表格不得只用无语义容器模拟。
- CON-FE-A11Y-002 键盘可达：所有核心操作、导航、弹窗、菜单、下拉、搜索和批量操作必须可通过键盘完成，并保留可见焦点。
- CON-FE-A11Y-003 焦点管理：Dialog、Drawer、Popover、Menu、Combobox 等浮层必须处理打开焦点、焦点约束、关闭后焦点返回和 Esc/外部点击语义。
- CON-FE-A11Y-004 标签与错误：表单控件必须有可读 label 或等价说明；错误提示、辅助说明和必填状态应与字段建立可感知关联。
- CON-FE-A11Y-005 状态表达：禁止只靠颜色表达成功、警告、危险、选中、禁用或错误；重要状态必须有文本、图标、aria、结构或等价辅助信息。
- CON-FE-A11Y-006 成熟基础优先：复杂交互组件应优先复用项目既有组件库、成熟 headless 基础或已验证组件；手写底层行为时必须说明键盘、焦点和语义覆盖。
- CON-FE-A11Y-007 紧凑不降级：紧凑 UI 可以减少无效高度，但不得牺牲可点击目标、可读性、焦点可见性、触控间距和错误可感知性。
