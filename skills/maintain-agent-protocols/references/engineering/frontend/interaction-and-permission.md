# 前端交互与权限

## 核心规则

- 列表页应优先复用统一筛选骨架，筛选变化必须重置分页。
- 时间字段必须使用共享格式化入口，避免页面内各自格式化。
- 小眉标、标签和分区标题必须承载真实语义，禁止只做装饰性英文文案。
- 同类功能应保持一致交互、反馈、空态、确认方式和错误呈现；当用户任务、风险级别或信息架构不同导致差异时，应说明场景理由。
- 删除、批量操作、全局放行等高影响交互必须有正式确认流程。
- 导航应优先使用清晰的一级入口和二级辅助入口；紧凑导航仍应保留图标、文本、tooltip 或等价可访问说明。
- 二级导航应支持搜索或最近访问，并映射到真实页面边界或稳定子视图。
- 登录态必须来自统一入口；菜单和入口可见性应来自后端权限数据。
- 401 和 403 响应必须进入统一反馈路径；隐藏 UI 不是最终权限边界。
- 若后端已提供稳定权限矩阵，前端不应再手写平行权限规则；若暂时没有稳定后端契约，必须说明例外边界。
- 页面改造前必须确认真实挂载入口、路由和宿主视图，避免只改未接线组件。

## 输出要求

- 说明同类功能交互一致性、权限反馈、高影响操作确认方式和展示控制边界。
