# UI 稳定性

适用前端页面、管理后台、SaaS 控制台、数据看板、配置页、表格页、表单页、Dialog、Drawer 和高频操作页的运行态 UI 验收。目标是保证不同分辨率、浏览器缩放、数据规模和长文本输入下，信息完整可见、布局稳定、操作可达、内容不重叠且样式不失真。

## 核心约束

- CON-FE-STABILITY-001 运行态验收：页面完成不能只依赖静态截图或单一开发设备效果；涉及用户可见页面、弹窗、表格、配置页或复杂组件时，必须以实际运行页面作为 UI 稳定性验收依据。
- CON-FE-STABILITY-002 桌面宽度边界：管理后台、桌面控制台或项目明确声明桌面优先时，默认最低支持宽度为 1280px；低于最低宽度允许整体横向滚动。面向移动端、公网页或响应式产品时，必须继承项目已有断点策略，不得套用桌面后台宽度假设。
- CON-FE-STABILITY-003 分辨率与缩放：桌面优先页面应覆盖 1366x768、1920x1080、2560x1440 和 3840x2160 中与目标用户匹配的视口，并检查 100%、125%、150% 浏览器缩放；不得出现内容遮挡、重叠、按钮消失、标题覆盖、页面错位或异常横向滚动。
- CON-FE-STABILITY-004 布局策略：页面主体应优先使用 Flex、Grid、百分比宽度、max-width、minmax、flex: 1 或等价自适应布局；禁止用固定宽高、固定 left/top 或 absolute/fixed 拼接主体结构。absolute/fixed 仅可用于浮层、吸顶、定位标记等局部场景，并需说明边界。
- CON-FE-STABILITY-005 文本可见性：中文长文本、英文标识、URL、JSON、IPv6、域名和长路径必须有可读策略；允许单行省略、换行、复制或横向滚动，但隐藏内容必须提供 Tooltip、hover、展开、复制或详情入口，不得用 overflow: hidden 直接掩盖问题。
- CON-FE-STABILITY-006 表格稳定性：日志、告警、事件、节点、用户、资产和配置列表默认优先使用表格或等价密集列表；表格列宽必须显式设计，长文本列应控制单元格展示并提供完整查看能力。表格可横向滚动，但不得无限压缩列宽导致不可读。
- CON-FE-STABILITY-007 卡片和网格：同一层级卡片应保持高度和视觉对齐稳定；卡片网格应使用 auto-fit、auto-fill、minmax 或项目等价布局策略，避免固定列数在宽屏或缩放场景下造成空洞、拥挤或错位。
- CON-FE-STABILITY-008 表单稳定性：长 label、长输入值、错误提示和操作按钮必须保持可达；禁止标签挤压输入框、按钮换行重叠、操作区溢出或错误信息覆盖字段。配置型表单应优先保证字段、说明、错误和操作区在缩放场景下可读。
- CON-FE-STABILITY-009 浮层可达：Dialog 和 Drawer 必须有视口约束和内部滚动策略；长表单、长表格或错误列表不得超出浏览器可视区域导致无法访问。焦点与键盘规则同时继承 `accessibility.md`。
- CON-FE-STABILITY-010 极限数据：页面验收必须覆盖空数据、少量数据、大量数据、长文本和异常内容；涉及列表或表格时，应至少说明 0 条、1-10 条、100+ 或 1000+ 数据中哪些已验证，未验证项必须记录原因和风险。

## 建议基线

桌面管理后台默认基线：

```text
最小宽度      → 1280px
桌面分辨率    → 1366x768、1920x1080、2560x1440、3840x2160
浏览器缩放    → 100%、125%、150%
长文本长度    → 50、100、200 字符
特殊内容      → 中文、英文、IP、IPv6、域名、URL、JSON
```

如项目已有更严格断点、浏览器矩阵、视觉回归或设计系统验收标准，以项目标准为准；如项目明确不支持某个分辨率、缩放或数据规模，交付说明必须写明依据。

- Dialog、Drawer、键盘和焦点：读取 `accessibility.md`。
- 组件状态和长文本状态：读取 `component-system.md`。
- UI 验证层级和视觉回归：读取 `testing.md`。
- 运行命令、E2E、storybook 和构建验证：读取 `tooling-and-verification.md`。

## 输出要求

- 说明本次页面是否属于桌面后台、响应式产品或项目特定断点范围，并说明采用的最小宽度或断点依据。
- 说明实际验证过的分辨率、浏览器缩放、数据规模、长文本和特殊内容；无法验证时说明原因、替代检查和剩余风险。
- 说明表格列宽、长文本查看、卡片高度、表单操作区、Dialog/Drawer 内部滚动和异常横向滚动的处理结论。
- 发现内容遮挡、重叠、按钮消失、标题覆盖、弹窗溢出、表单错位、卡片高度错乱或异常滚动时，必须先修复再交付。
