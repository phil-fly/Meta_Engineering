# 前端请求与数据加载

## 核心规则

- 列表查询先按 `list-query.md` 分类；分页列表必须服务端分页，小集合或枚举列表可不分页但必须说明上限和刷新策略。
- 会影响结果全集的查询条件必须由真实数据源驱动，筛选、排序、搜索和统计不得只在当前页数组上补算。
- 前端加载必须按需进行，不默认全局预取大集合或无界缓存。
- 页面首次进入、刷新或展示 loading 状态时，必须读取 `state-and-cache.md` 并遵守 `CON-FE-STATE-008`，避免普通页面数据阻塞页面壳层。
- 筛选控件必须反映真实后端能力；后端不支持时应隐藏、禁用或明确标记不可用。
- API client、请求声明、服务端缓存、失效刷新和 URL 状态应分别读取 `state-and-cache.md` 与 `tooling-and-verification.md`；本文件只约束数据加载和真实能力边界。

## 输出要求

- 说明查询类型、是否分页、数据上限、刷新策略，以及筛选、排序、搜索、统计是否由真实后端能力支撑。
- 说明请求声明、缓存失效或 URL 状态是否需要读取 `state-and-cache.md`。
