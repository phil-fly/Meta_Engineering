# 路由卡片模板

```markdown
## <Route Name>

## 适用场景

- 说明何时读取本路由。

## 路由状态

```text
状态：项目证据支持 / 条件适用 / 通用治理
证据：
适用条件：
```

## 必读入口

- 相关路由：
- 相关场景手册：
- 相关检查清单：

## 触发门禁

```text
触发条件：
相关 WF-*：
约束编号：
门禁节点：预检门 / 变更门 / 验证门 / 报告门
```

## 核心规则

- 使用可执行、可验证的规则表达。
- 未经目标仓证据验证的规则使用 `应`、`建议` 或 `如项目采用...`，不要写成项目级 `必须`。
- 避免项目私有路径和一次性 workaround。
- 已在项目协议、场景手册或检查清单展开的高频规则，只写锚点引用和本路由差异。

## 验证与输出

- 说明完成时应验证什么。
- 说明最终回复应包含什么。
```
