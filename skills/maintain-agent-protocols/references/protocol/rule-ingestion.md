# 规则摄入指南

用于把新的协作要求摄入 AI Agent 协议体系，并判断它属于原则、约束还是执行流程。

## 摄入流程

1. 识别规则类型：原则、约束、执行流程、模板格式、检查项、知识背景或临时约定。
2. 判断适用范围：用户级、项目级、工程域、任务场景、审查验收或一次性任务。
3. 判断是否影响触发：它是否改变 Agent 何时加载某个入口，或只是入口加载后的执行规则。
4. 选择维护位置：只放到一个主真值源，其他位置只保留入口或引用。
5. 检查冲突、重复和反证：确认是否与高优先级规则、项目协议或既有路由冲突，并确认它不是一次性约定或项目例外。
6. 验证执行率：确认 Agent 能在真实任务中找到入口、理解规则并输出闭环结果。

## 类型判定

```text
原则      → 长期稳定、跨任务通用、指导取舍
约束      → 必须遵守的边界、禁止项、兼容性、安全或质量要求
执行流程  → 某类任务的步骤、输入输出、验证方式和闭环要求
模板      → 可复用文件骨架、报告格式或输出结构
检查项    → 审查、验收、巡检时逐项核对的标准
知识背景  → 解释性材料、设计背景、经验沉淀
临时约定  → 一次性范围决策、实验说明或线程内任务约束
```

## 维护位置

| 类型 | 默认维护位置 | 是否进入入口索引 | 是否进入用户级/技能级触发 | 说明 |
| --- | --- | --- | --- | --- |
| 用户级原则 | `AGENTS.md` 或 `ai-agent-protocols/user/AGENTS.md` | 是 | 高频时是 | 只保留高频入口、优先级、任务分类和长期原则。 |
| 项目级约束 | 项目根协议、`CODEX.md`、`CLAUDE.md` 或 `ai-agent-protocols/project/AGENTS.md` | 是 | 否 | 放仓库专属架构、命令、测试、业务边界和项目例外。 |
| 工程域约束 | `ai-agent-protocols/routes/<domain>/` | 是 | 否 | 放 UI、后端、API、安全、性能、平台等可执行规则。 |
| 执行流程 | `ai-agent-protocols/playbooks/` | 是 | 主流程时是 | 放开发、架构、安全审查、性能审查、排障、调研等步骤。 |
| 检查项 | `ai-agent-protocols/checks/` | 是 | 否 | 放审查和验收清单，不放长流程或教程。 |
| 模板格式 | `ai-agent-protocols/templates/` | 由创建/维护入口引用 | 否 | 模板文件不决定主流程；模板生成请求由协议创建或维护任务触发。 |
| 业务规范 | 项目 Spec、OpenSpec 或 ADR | 视项目而定 | 否 | 涉及 API、数据结构、配置、权限或架构时优先进入规范。 |
| 长期知识 | Wiki、ADR 或设计文档 | 否 | 否 | 存背景和经验，不替代协议约束。 |
| 临时约定 | 当前线程、Issue 或任务计划 | 否 | 否 | 默认不沉淀为长期协议，除非转化为可复用规则。 |

## 原则摄入

原则应满足：

- 长期有效。
- 跨任务可复用。
- 用于处理取舍和冲突。
- 不包含具体命令、长流程或检查清单。

维护策略：

- 跨项目原则进入用户级协议。
- 仓库专属原则进入项目级协议。
- 工程域原则进入对应 `routes/<domain>/index.md`。
- 原则不直接写成教程；需要解释时放 Wiki 或设计文档。

触发策略：

- 高频原则可作为用户协议或项目协议的入口规则。
- 低频原则不要放进触发入口，避免增加长期上下文成本。

## 约束摄入

约束应满足：

- 有明确适用范围：约束谁、哪类任务、哪个环境或哪个阶段。
- 有生效条件：何时适用，哪些操作、路径、环境或风险等级会触发该约束。
- 有规则正文：使用 `必须`、`禁止`、`默认`、`仅当` 写出可执行要求，而不是只写 `安全`、`性能`、`部署` 之类标签词。
- 有验证方式：能通过命令、检查项、测试、代码审查点或运行证据判断是否遵守。
- 能判断违反与否：违反后能定位到具体行为、输入、输出或配置。
- 如存在例外、项目私有条件或上层覆盖，必须写明例外或优先级来源。

最低记录格式：

```text
约束名称：
适用范围：
生效条件：
规则正文：
验证方式：
例外/优先级：
```

禁止写法：

- `安全`
- `性能`
- `使用 pnpm`
- `遵循规范`

推荐写法：

```text
约束名称：生产密钥注入
适用范围：CI、部署脚本、生产环境配置
生效条件：新增、修改或轮换生产密钥时
规则正文：禁止把生产密钥提交到仓库；必须从密钥管理系统注入；默认日志中不输出原始密钥值
验证方式：检查 CI 配置、部署脚本和日志脱敏配置
例外/优先级：本地开发桩密钥仅可用于 dev profile，生产环境禁用
```

维护策略：

- 安全、权限、数据访问、性能等工程约束进入 `routes/`。
- 项目专属命令、版本、架构、业务边界进入项目级协议或项目 Spec。
- 涉及 API、数据结构、配置、权限模型或系统架构的约束，应优先确认是否需要同步项目规范。
- 禁止把同一约束原文复制到用户协议、项目协议和路由多处；上层只保留入口。

触发策略：

- 会改变任务入口选择的约束，应进入路由索引。
- 只在入口加载后执行的细则，应进入具体路由文件。
- 不作为任务入口的约束，不应写进 description 或用户协议顶层。

## 执行流程摄入

执行流程应满足：

- 有明确任务类型。
- 有步骤顺序。
- 有输入、输出和验证方式。
- 有闭环要求。

维护策略：

- 通用任务流程进入 `playbooks/`。
- 工程域流程进入对应 `routes/<domain>/`。
- 审查或验收流程中的清单进入 `checks/`，不要塞进 `playbooks/`。
- 一次性执行计划保留在线程或 Issue，不沉淀为长期流程。

触发策略：

- 能独立决定任务主流程的流程，应在用户协议的任务分类或场景入口中出现。
- 只是某类工程域内部的子流程，应由工程路由索引触发，不进入用户协议顶层。

## 是否触发判断

判断一个规则是否需要进入触发入口：

```text
用户是否会用它来描述任务？        → 可能需要触发
它是否决定先读哪个文件？          → 需要触发
它是否只是执行中的细节？          → 不直接触发
它是否低频、长尾或项目私有？      → 不进入用户级触发
它是否会误触发其他任务？          → 降级为子路由或细则
```

进入入口索引和进入用户级/技能级触发不同：

- 入口索引用于“已触发后应该读哪个文件”。
- 用户级/技能级触发用于“用户一句话是否应激活本协议能力”。
- 高频任务、主流程和用户常用表达可以进入用户级/技能级触发。
- 低频细则、项目私有规则和执行中的约束只进入索引或具体文件。

## 技能入口同步

当摄入结果会影响技能发现或技能主流程时，必须同步最终技能入口，而不只更新 reference。

需要同步的位置：

```text
SKILL.md frontmatter description  → 补充用户真实触发词和 Do not use 边界
SKILL.md 工作流 / 读取顺序        → 补充何时读取新 reference
references/index.md               → 补充总入口导航
场景 index.md                      → 补充局部读取顺序和适用任务
agents/openai.yaml                 → 如能力对用户可见，更新 default_prompt 或 short_description
```

同步判断：

```text
用户会直接这样提问       → 更新 description
会改变主工作流           → 更新 SKILL.md 工作流
只是某个领域下的细则     → 只更新对应 index 和 reference
用户界面入口应体现新能力 → 更新 agents/openai.yaml
```

禁止：

- 只新增 reference，却不更新任何可发现入口。
- 只在 description 中加触发词，却没有可读取的执行细节。
- 为低频细则扩写 description，导致普通工程任务误触发。

## 反证检查

把规则提升为长期协议前，先检查是否存在反证：

- 是否只是当前项目的例外，而不是跨项目原则？
- 是否只是一次性任务约定，而不是长期规则？
- 是否只是解释性知识，而不是可执行约束？
- 是否已有更高优先级规则覆盖？
- 是否会和既有任务入口产生误触发？
- 是否能通过更低层级的路由或模板解决，而不需要进入用户协议顶层？

示例：

- `前端列表查询接口`：高频任务入口，应进入工程路由索引，并指向组合路由。
- `枚举列表不一定分页`：执行细则，应进入列表查询组合路由和 API 约束，不进入用户协议顶层。
- `更新 Wiki 前先确认`：长期协作原则，可进入用户级或项目级协议。
- `某项目使用 pnpm test`：项目约束，应进入项目级协议，不进入用户级协议。

## 交付要求

摄入或调整规则后，回复应说明：

- 新规则类型。
- 主维护位置。
- 是否进入入口索引。
- 是否进入用户级/技能级触发。
- 是否同步 `description`、`SKILL.md` 工作流、索引和 `agents/openai.yaml`。
- 关联位置是否同步。
- 冲突或重复是否处理。
- 反证检查结果。
- 验证方式和剩余风险。
